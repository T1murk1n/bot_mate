# Telegram-бот расписания

Python 3.10 или новее. Данные расписания: `schedules_all.json`, справочники: `schedule_details.json`.

Для локального запуска создайте виртуальное окружение, установите зависимости из
`requirements.txt`, скопируйте `.env.example` в `.env`, укажите `BOT_TOKEN` из
BotFather и запустите `python bot.py`. Не публикуйте `.env` и приватные SSH-ключи.

Фамилию преподавателя можно вводить сразу, через кнопку или командой
`препод Андреев`. Поиск понимает регистр, `е/ё`, основные падежные формы фамилий,
ФИО и инициалы. Если подходит несколько преподавателей, бот попросит уточнить имя.
Опечатки дают подсказку, без автоматической подстановки другого человека.
Группы можно вводить с пробелами и разными дефисами даже во время поиска
преподавателя. Список групп открывается по `/groups`, справка — `/help`,
выход из поиска — `/cancel`.

Команда `Где Андреев` показывает расписание преподавателя на всю текущую неделю
с понедельника по воскресенье: даты, номера и время пар, предметы, группы,
аудитории и адреса корпусов. Учитывается чередование учебных недель; общие пары
нескольких групп объединяются. Выбирать свою группу не требуется. Можно отправить
`Где`, а фамилию — следующим сообщением. При совпадении фамилий бот попросит
уточнить имя. Если ФИО отсутствует в справочнике, используются инициалы из
расписания. Длинное расписание отправляется несколькими сообщениями.

Для просмотра расписания на конкретный день отправьте `05.11.2026`, `05.11`,
`2026-11-05` или `расписание на 05.11`. Без года используется текущий год;
двузначный год трактуется как 20xx. Также доступны `сегодня`, `завтра`, `вчера`,
`послезавтра` и кнопка «На дату». Если группа ещё не выбрана, бот запомнит дату
и попросит группу. Расписание доступно начиная с 26.10.2026.

## Развёртывание на Ubuntu

Загрузите исходники и папку `deploy` на сервер. Сохраните `BOT_TOKEN=...` в
`/etc/bot-mate/bot.env`, задайте владельца `root:root` и права `600`.
Из папки проекта выполните `sudo bash deploy/install.sh`.

Установщик создаёт отдельного пользователя `bot-mate`, виртуальное окружение и
версионный каталог в `/opt/bot-mate/releases`. Перед переключением текущей версии
он проверяет расписания, токен Telegram и отсутствие webhook. Установленные версии
зависимостей сохраняются в `requirements.lock.txt` внутри каждого релиза.

Служба `bot-mate` запускается после перезагрузки и перезапускается при сбое.
Часовой пояс процесса: `Asia/Tbilisi` (UTC+4); его можно изменить строкой `TZ=...`
в `/etc/bot-mate/bot.env` с последующим перезапуском службы.

```sh
sudo systemctl status bot-mate --no-pager
sudo journalctl -u bot-mate -n 50 --no-pager
sudo systemctl restart bot-mate
```

Для обновления загрузите новую копию исходников и повторите запуск установщика.
Предыдущие релизы сохраняются. Выбранные пользователями группы хранятся в памяти
и сбрасываются при перезапуске бота.

Локальная папка `.deploy` содержит приватный SSH-ключ и вспомогательные файлы
подключения. Она исключена из Git; не загружайте её на сервер вместе с проектом.
